# Experiment 9 — branch-emitted leaf bloom

This is a **hierarchical foliage rig**: trunk → branch → leaf cluster. A **branch-local socket** is a fixed attachment coordinate inside one branch asset. **Cluster bloom** is the local scale-and-settle growth of a cluster from that socket. **Secondary action** is the small one-time rotation/overshoot that follows the main branch movement. **Stagger** offsets overlapping bloom windows so the crown develops as a wave instead of one simultaneous reveal.

The family is deliberately bounded: three PixelLab-authored registered clusters are reused across eight sockets (fan 3×, rosette 3×, tuft 2×). Mirrors, scale, rotation, asymmetric branch positions, overlapping timings, and the recorded painter order make reuse inspectable without requiring eight unique assets. Parent branch wood paints over each cluster neck, so visible foliage originates from wood rather than floating beside it.

Round 1’s key-pose island formation is the untouched control. It remains below the owner LOOK bar and is held only so this canopy technique can be compared directly.

Look specifically for **popcorn leaves**, **repeated stamps**, **busy shimmer**, **mechanical stagger**, **socket exposure**, and a **sparse crown**. Absence of those failures is not owner approval; the hosted mock still awaits owner LOOK.
