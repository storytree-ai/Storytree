The shipped map’s ground — four arms, one thing each

The island the studio actually ships (164 parcels), drawn four times. Each arm differs from the one before it in exactly one thing, so the ladder reads left to right as the adoption itself:

flat    the shipped map on 2026-08-29
relief  + the land’s relief field — crossed 2026-08-30
banded  + the authored shade ladder — crossed 2026-08-30, and what ships now
treated + the grain octave — REFERENCE ONLY, see below

Same parcels, same status colours, same framing, same view direction. The light and the framing direction are imported from the shipped files rather than transcribed, so this is the product’s land and not a plausible one.

What each rung actually does

relief adds no triangles, no draw call and no attribute channel: the vertices this ground already emitted simply stand where the land is and face the way it turns. Under MeshStandardMaterial that arrives as a smooth lambert gradient.

banded replaces that material with src/banded-ground-material.ts, which quantises the lighting onto the four authored rungs and selects an already-rounded token × level colour. It is unlit — the scene lights do not reach it — because the ladder computes its own lambert against the authored LIGHT_DIRECTION. Every pixel it can deliver is one of 24 authored entries; the driver refuses a run in which it delivers anything else.

treated is the experiment’s own material (harness/banded-material.ts) wearing the grain octave the approved Cycles render used. It is here because a component that crosses correctly has not thereby delivered the look, and the honest way to report a crossing is beside the ceiling it is reaching for. It is not adoptable as it stands: its colour half mixes a noise ramp into the delivered colour, which is off-palette by construction.
