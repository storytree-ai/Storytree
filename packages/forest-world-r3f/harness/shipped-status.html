The map still tells the truth — all six statuses, one forest

demonstrate-the-map-still-reports-truth on adopt-the-land-into-the-shipped-map-arc, end-state item 3: every capability’s status must read correctly off the finished land, demonstrated rather than asserted. ADR-0475 D2 is the frame this page answers to: “the land is uniform within an island, and carries the story’s own state … island-level state reads off the ground at the opening view.” So the question below is exactly the map’s own truth claim for the ground: does each island’s ground read as that island’s own state, and as no other — over the real fixture forest (35 islands: 21 healthy, 8 proposed, 2 building, 2 mapped, 1 unknown, 1 unhealthy), at both of this arc’s zooms.

⚠⚠ The shipped map carries status as COLOUR ONLY, and FIVE colours over SIX states (ADR-0462 D1/D2; the earlier ADR-0461 is superseded by ADR-0475). proposed and building share one authored token — the owner’s own words: “if something is building just color it yellow because its basicly the same as proposed, theres no value add.” That is a DECISION measured on delivered pixels, not a gap this page reports as a defect: the pair is expected to read as one family, and the pair-separation table below shows it at exactly zero. Only healthy wears the grass layer (GRASS_STATUS_GATE, ADR-0492 D1) — every other layer this ground now carries (sand, the worn path, rock on slope, the cliff normal as detail relief) MODULATES the status ramp and never replaces it (ADR-0490 D5), which is exactly what could have quietly eroded the six-way distinction this page checks for.

⚠ The terrain vocabulary that separates proposed from building is not on this page. harness/terrain.html carries a channel that WOULD tell the pair apart, but adoption onto the shipped map was scoped out of a separate increment (name-the-four-states-as-terrains). So the pair reads as one family here by construction, on the ground exactly as it ships — adopting that channel is a separate, later event.

⚠ The outcome test this page applies is ADR-0489 D3’s own: “look at the final render and ask: can I tell what state this island is in?” — asked here of every one of the 35 islands at once, by an instrument rather than by eye.
