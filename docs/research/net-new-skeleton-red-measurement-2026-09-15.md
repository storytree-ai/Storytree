# Net-new red under a spine-generated skeleton — measurement, 2026-09-15

**Arc** `batched-test-authoring-arc` · **increment** `batched-test-authoring-arc-inc-05` · **measured on**
Windows 11 (ARM64), Node 24.15.0 (tsx 4.22.4), Bun 1.4.0, vitest 3.2.6, at `f8fd24e5`. It builds on
[`batched-red-attribution-probe-2026-09-14.md`](batched-red-attribution-probe-2026-09-14.md) (the
probe) and reuses its reporter module (A.3), its per-test readers (A.4) and its route census (A.6).
Nothing the probe measured was re-run.

**The question.** ADR-0573 D4 keeps every unit whose declared red is structural at one test per build:
a static import of a module that does not exist yet stops the test file from loading, and a file that
does not load reports nothing per test. D4 names one admissible widening — a NON-THROWING skeleton,
generated by the spine from the test file's own imports, in which every imported symbol exists and
returns nothing — and declines to commission it until two things are measured over the landed tests of
today's structural-red units:

1. **False refusals.** How many real tests go red for a reason other than their assertion, which C5
   refuses, and how many pass before any code exists, which C4 refuses?
2. **Generability.** Can a stub be generated for the corpus's real import shapes? Which shapes need a
   rule of their own, and does any such rule make a real assertion pass against the stub?

## Outcome

1. **The measurement does not support commissioning a skeleton. Net-new units stay one test per
   build.** Against D4's skeleton exactly as written (K1), 8 of the 73 measurable units would have a
   whole test file's cluster accepted at CONFIRM_RED — every test that passes against the landed code
   going red for its assertion's reason. The other 65 would be refused, and ADR-0573 D3 refuses a
   cluster outright rather than observe it at file level.
2. **Most real tests fail before their assertion runs.** Of the 948 tests that pass against the landed
   code, 643 (68%) go red under K1 with some other error — 439 of them by reading a property of the
   `undefined` a stub returned — 266 (28%) go red on their assertion, and 39 (4%) pass.
3. **A rule of its own buys reds and manufactures passes.** An absorbing stub (K2: every call,
   construction and member read returns another stub) moves 726 of the 948 (77%) to an assertion red,
   and 29 of 73 units advance as-is. But 28 of its 51 early passes exist only because of that rule —
   truthiness of a stub-derived value (18), two results compared as different (7), an assertion loop
   over a stub that iterates as empty (3) — and not one of them passes against the returns-nothing stub,
   which is what an empty implementation looks like to a test. Declaring as guard-rails only the passes
   an empty implementation also satisfies takes K2 to 33 of 73, short of a majority. Reaching 44 would
   mean declaring 28 guard-rails that are not guard-rails.
4. **No uniform stub escapes, and the reasons are structural (§5).** An `undefined` return breaks
   every dereference before the assertion, while an object return satisfies truthiness. A constant
   identity satisfies "same input, same output", while a fresh one satisfies "different input,
   different output". An effect the test reads through another channel — a file, a server, the DOM —
   is out of reach of any return value: the DOM alone is 60 tests in 10 of the 18 vitest units, under
   both stubs.
5. **Generation is not the obstacle.** Every measurable unit got a skeleton that loaded, on all three
   runners and across every import shape the corpus uses (§4). Three shapes need a rule of their own —
   a missing export in a module that already exists, a new module re-exported through an existing
   barrel, and a subject the test reaches through a spawned process, where there is nothing to generate
   from — and what a binding IS (function, class, constant, schema) cannot be read from its import,
   only from how the test uses it.
6. **The finer grain the arc actually wants does not rescue K1.** A real cluster is "the contracts
   sharing a fixture or seam", smaller than a file. Taking each contract's own tests as its cluster,
   38 of 199 contracts (19%) would advance under K1 and 136 (68%) under K2. The K2 figure is the one a
   future proposal would have to argue from, carrying K2's manufactured passes and a third of contracts
   still refused — for reasons (§3.3) a brief cannot predict, because the brief is written before the
   tests exist.

## 2. Method

- **Scratch, outside the repository.** `git archive HEAD` into a temporary directory,
  `pnpm install --frozen-lockfile --prefer-offline`, then a throwaway `git init` and commit in that
  copy — unrelated to the repository — so every restore could be checked with `git status`. It read
  clean after every run. No generated file was ever written into a real package.
- **The modules under test** are the unit's `real.sourceFile` and `scope.sourceGlobs` files that its
  landed test file imports DIRECTLY (`.js` → `.ts`/`.tsx`, extensionless, and `@storytree/*` package
  exports resolved).
- **The names** are every non-type-only binding the test imports from such a module — for a namespace
  import, the members the test touches — widened by the names other modules in the test's load graph
  import from the same module, without which the file would fail to link.
- **The variants.**
  - **K1 — ADR-0573 D4 as written.** Every name is a plain function returning `undefined`: callable,
    constructible (`new` yields an empty instance), with no members of its own.
  - **K2 — an absorbing stub: one "rule of its own", priced.** Every name is a proxy that is callable
    and constructible, and every call, construction or member read returns another such proxy. It is
    never a thenable (so `await` settles), converts to `""` or `NaN`, and iterates as empty.
  - **K1x — history-shaped.** A module that was absent when the unit's tests arrived gets K1 whole; a
    module that existed keeps its landed code and gains K1 stubs only for the names it lacked then
    (`export * from` the real module beside local exports, which win). It differs from K1 for 7 units.
- **The run.** The unit's test file alone, under its runner, per test: node:test through the probe's
  reporter module with `--test-force-exit`, bun through `--reporter=junit`, vitest through
  `--reporter=json`. First against the landed code (base), then each variant, restoring the module
  bytes after each run and checking them.
- **The join.** Each declared test from ADR-0126's static read (`analyzeObservedTests`), joined on its
  full title path to the report, with the probe's readers and a vitest json reader (Appendix B.4).
- **The classification** of every test that PASSED at base: an **assertion red** (what C4 and C5
  demand), a **red of another kind** (C5 refuses), **passed early** (C4 refuses unless the story
  declares a guard-rail, ADR-0572), or **not reported / not run / ambiguous** (C1–C3 refuse).
- **The unit of account is the unit.** D3 refuses a cluster at CONFIRM_RED when ANY new test fails a
  check, and never falls back to file-level observation, so the decisive figure is how many units'
  clusters would ADVANCE. Per-test rates are reported beside it and do not decide.
- **The decision criteria were written down before the full run finished** (Appendix A), after a
  four-unit sample in which no unit advanced under K1, so they are not blind to that sample. One term in
  them needed defining after the early passes were listed: a "plausibly declarable guard-rail" is taken
  to be a test the returns-nothing stub also passes — ADR-0572's own definition of a guard-rail, a test
  an empty implementation already satisfies.

### The instrument, checked before it was believed

The scripts are plain JavaScript run under tsx, so nothing typechecked them. In their place:

1. **The census reproduces the probe's figures at the probe's commit**, exactly (§1).
2. **Every run was reconciled against the runner's OWN summary** — node:test's `ℹ pass` / `ℹ fail`
   lines, bun's console `N pass` / `N fail`, vitest's `Tests … (N)` line — an independent reader of the
   fact the per-test report carries. 288 runs; one disagreement, explained: `local-backend-boot` under
   K2 was killed at the six-minute process cap (SIGTERM) after 5 of its 38 tests had streamed their
   rows and before node:test printed a summary, so the summary reads zero.
3. **The per-unit tallies were computed twice by independent code** — the harness's own tally line
   as each unit finished (Appendix B.5) and the fold over the stored results (B.6) — and all 212
   unit-and-variant tallies agree (B.7).
4. **One unit was run by hand before the harness existed** (`traversal-trace-sink` against K1: three
   assertion reds, three `ENOENT`, three `TypeError`), and the harness reproduced it exactly.
5. **The generators were run against the probe's own fixtures** (A.1: the eight-test cluster and G1),
   in a fresh `"type": "module"` package, on node and bun (B.8). K1 reproduces the probe's S1 column
   exactly — the three real tests red for the assertion's reason, H1–H4 passing, W1 a `TypeError`, G1
   passing — and K2 classifies all eleven identically, so the absorbing variant keeps the separation
   D4 relied on for every hollow shape the probe measured.

### Traps met — each cost a re-run, and each would cost the next measurement the same

1. **The workspace's `typescript` is the native 7.x build, with no JavaScript compiler API**
   (`require("typescript")` yields only `{ version, versionMajorMinor }`; ADR-0400). A static read has to
   go through the `typescript5` alias, as `contract-coverage.ts` does.
2. **A repository copy installed under the session's scratchpad cannot start vitest.** vite's
   `package.json` landed at 263 characters, past Windows MAX_PATH; Node's package-scope reader then fails
   vite's own `#module-sync-enabled` subpath import with `ERR_PACKAGE_IMPORT_NOT_DEFINED`, and vitest dies
   loading its config. `fs` reads of the same file succeed and node:test and bun runs were unaffected,
   so only the vitest units fail — as a startup error that reads like a broken config. A shorter scratch
   root fixed it. (Filed as friction `session-scratchpad-repo-copy-breaks-vitest-on-max-path`.)
3. **A stub never hands back a closable handle.** A node:test file whose tests had all reported sat open
   until the process cap, holding a server the stubbed route never closed. `--test-force-exit` was added
   to every node run, base included, so the variants differ only in the subject. On Windows the flag
   races a closing handle: three files that open and close a server (`backend-chat-reset-route`,
   `boot-read-routes`, `codex-feedback-endpoint`) ended with a libuv assertion
   (`!(handle->flags & UV_HANDLE_CLOSING)`, `src\win\async.c`) and a synthetic failing FILE row after
   every test had passed, at base as well as under the stubs. Two re-runs of each without the flag were
   clean — exit 0, every test reported, no file row — so it is the harness's artifact, not the files',
   and the declared tests' own rows, which are all this measurement classifies, were unaffected.
4. **A stubbed request handler hangs every test to its timeout.** `write-broker` mounts the stub as an
   HTTP handler that never ends a response, so each test waits out the per-test timeout; at 60 s its ten
   tests outlive the six-minute process cap before vitest writes its report, and every test would read
   "not reported" when each in fact timed out. The harness was stopped there, the copy restored from its
   snapshot, and the twelve units not yet measured ran at a 15 s per-test timeout; the other 64 ran at
   60 s. A test that does not hang is unaffected by the value, and each stored result records it.
5. **The harness's first name policy widened a module the test never imports** — one reached only
   through another importer (`backend-chat-reset-route` → `packages/drive/src/orchestrate.ts`). Caught in
   the import census before the full run; the widening now applies only to modules the test imports
   itself.

### 3.4 The early passes

**Under K1, all 39 are tests an empty implementation satisfies**, because K1 IS one: 32 exercise the
module under test and assert that nothing happens or nothing comes back ("an absent parent session is
a total no-op", "returns undefined for install plumbing", "renders nothing without the feature flag",
"the module exports no `withPresence`", "two equal inputs hash equally"), and 7 exercise nothing in it at
all (a boundary check that reads the module file's own import lines, another module's schema). Each is
a guard-rail in ADR-0572's sense, so under a skeleton the story would have to declare every one.

**Under K2, 23 of the 51 also pass under K1 and 28 pass only under K2** — the absorbing rule turning a
real assertion into a pass that an empty implementation does not produce:

- **18, truthiness of a stub-derived value** — `assert.ok(line.includes("abc1234"))` passes because the
  stub's `includes` returns a truthy stub (`verdict-line` ×4, `experience-rollout-guardrails` ×7,
  `gate-ci-parity` ×3, `forest-scene-model` ×3, `library-standson-corpus-bootstrap`).
- **7, two results compared as different** — a fresh stub per call satisfies "a changed field changes
  the hash" (`criterion-detail-hash-anchor` ×5), "each role gets a distinct colour"
  (`colour-by-subagent`) and "the result does not alias its input" (`source-drift`).
- **3, an assertion loop over a stub that iterates as empty**, so the assertions never run
  (`criterion-detail-pointer`, `witnessable-verdict`, `repo-selection`).

**The identity pair, on one unit.** `criterion-detail-hash-anchor` passes its four determinism tests
early under K1 (`undefined` always equals `undefined`) and its five sensitivity tests early under K2 (a
new proxy never equals another). No uniform stub fails both.

## 5. Why no uniform stub escapes

A stub is ONE value standing in for every behaviour a test might probe, so every choice it makes
satisfies some real assertions and breaks others before they run:

1. **What a call returns.** `undefined` (K1) makes every dereference throw before the assertion — a
   property read, a destructure, a spread, a `JSON.parse` of a response body, a schema `parse` of the
   result. An object (K2) survives all of those and instead satisfies truthiness
   (`assert.ok(x.includes(…))`), makes a loop over its members empty so the assertions inside never run,
   and breaks an explicit `.then(…)` or a use as a URL.
2. **Identity across two calls.** A constant return satisfies "same input, same output"; a fresh return
   satisfies "different input, different output". `criterion-detail-hash-anchor` measures both.
3. **Effects outside the return value.** A test that reads the file the subject should have written
   (`ENOENT`), waits on a server the subject should have answered (the per-test timeout), or queries the
   DOM a component should have rendered (`TestingLibraryElementError`) fails on that channel before any
   assertion, whatever the stub returns.
4. **Contracts whose correct behaviour is to do nothing** pass against an empty stub by construction.
   They are real guard-rails, and C4 refuses each unless the story declares it.
5. **Tests in the file that never touch the module under test** pass against any stub.

A red author could be briefed to write tests that do not dereference a result before asserting on it.
That would be the tests shaping themselves around the stub — the lever D4 withholds from a model — and it
would weaken what the tests check in order to satisfy the observation of them.

## 6. What this does not establish

- **Tests a red author would write for a net-new cluster.** These are landed tests, written against
  real code over many builds.
- **Real cluster sizes.** A whole file over-counts refusals against a real cluster; the one-contract
  grain (§3.2) is the bound from the other side, and no grain in between was measured.
- **Another design of "a rule of its own".** K2 is one. A thenable variant would repair the 30 explicit
  `.then(…)` calls and break every awaited dereference; a memoising variant would pass both identity
  directions. Neither was run.
- **Another platform or a second run.** Windows 11 ARM64 only, one run per unit and variant, no Linux or
  CI; twelve units at a 15 s per-test timeout and the other 64 at 60 s.
- **An exact history.** The introduction of a unit's tests is read from a contract-id pickaxe and a file
  creation; module renames are not followed.
- **The four tests whose title paths could not be joined** (§7) are excluded, not classified.

## Appendix A — the decision criteria, as written before the full run finished

Disclosure: written after the 4-unit validation sample (traversal-trace-sink, library-standson-schema-admission,
review-mode-toggle, criterion-detail-hash-anchor), in which NO unit had every base-green test go red for the
assertion's reason under K1. So these criteria are not blind to that sample.

What ADR-0573 D3 makes decisive: a CLUSTER brief is refused at CONFIRM_RED if ANY new test fails C1-C7. So the
unit of account for "does batching reach this unit" is the UNIT, not the test:

- A unit's cluster would ADVANCE under a skeleton only if every base-green test in its file reds with the
  assertion kind (C4 + C5), is reported (C1/C2), and ran (C3). Any early pass needs a guard-rail declaration
  (ADR-0572) or refuses; any wrong-kind red refuses outright.

The measurement SUPPORTS commissioning a uniform spine-generated skeleton only if ALL hold:

1. Under ONE uniform variant (K1 = ADR-0573 D4's literal "returns nothing"; or K2 = absorbing, i.e. a rule of
   its own), a MAJORITY of measurable units advance a whole-file cluster (zero wrong-kind, zero unreported,
   zero not-run), counting a unit with early passes as advancing only if those passes are plausibly
   declarable guard-rails.
2. The shapes where generation fails or needs a rule of its own are either rare, or detectable from the test
   file BEFORE the brief is written (so D3's "routing decided when the brief is written" can fall back to one
   test per build without a refused cluster).
3. No rule of its own that rescues wrong-kind reds makes a real ASSERTION pass early at a rate that would
   convert refusals into silent advances (an early pass is a C4 refusal — not silent — but a rule that turns
   many reds into passes moves cost onto guard-rail declarations that are not guard-rails).

Otherwise: record the measurement and keep net-new units at one test per build, noting the outcome in place
on ADR-0573 D4.

Per-test rates are reported too, but they do not decide: a 90% per-test assertion-red rate over files of ten
tests still refuses most clusters.

/** What each exported name of a module IS (function / class / const-object / enum / type / …). */
function exportKinds(rel, seen = new Set()) {
  if (seen.has(rel)) return { names: new Map(), stars: [] };
  seen.add(rel);
  const sf = parseRel(rel);
  const local = new Map();
  const initKind = (init) => {
    let e = init;
    while (e !== undefined && (ts.isAsExpression(e) || ts.isParenthesizedExpression(e) || ts.isSatisfiesExpression(e))) e = e.expression;
    if (e === undefined) return "const-uninitialised";
    if (ts.isArrowFunction(e) || ts.isFunctionExpression(e)) return "const-function";
    if (ts.isObjectLiteralExpression(e)) return "const-object";
    if (ts.isArrayLiteralExpression(e)) return "const-array";
    if (ts.isStringLiteralLike(e) || ts.isNumericLiteral(e) || ts.isTemplateExpression(e) || e.kind === ts.SyntaxKind.TrueKeyword || e.kind === ts.SyntaxKind.FalseKeyword || ts.isPrefixUnaryExpression(e) || ts.isRegularExpressionLiteral(e)) return "const-literal";
    if (ts.isCallExpression(e)) return "const-call-result";
    if (ts.isNewExpression(e)) return "const-instance";
    if (ts.isClassExpression(e)) return "class";
    if (ts.isIdentifier(e) || ts.isPropertyAccessExpression(e)) return "const-alias";
    return "const-other";
  };
  for (const st of sf.statements) {
    if (ts.isFunctionDeclaration(st) && st.name) local.set(st.name.text, "function");
    else if (ts.isClassDeclaration(st) && st.name) local.set(st.name.text, "class");
    else if (ts.isInterfaceDeclaration(st) || ts.isTypeAliasDeclaration(st)) local.set(st.name.text, "type");
    else if (ts.isEnumDeclaration(st)) local.set(st.name.text, "enum");
    else if (ts.isModuleDeclaration(st) && ts.isIdentifier(st.name)) local.set(st.name.text, "ts-namespace");
    else if (ts.isVariableStatement(st)) {
      for (const d of st.declarationList.declarations) if (ts.isIdentifier(d.name)) local.set(d.name.text, initKind(d.initializer));
    } else if (ts.isImportDeclaration(st) && st.importClause) {
      const c = st.importClause;
      if (c.name) local.set(c.name.text, "imported");
      if (c.namedBindings && ts.isNamedImports(c.namedBindings)) for (const s of c.namedBindings.elements) local.set(s.name.text, "imported");
      if (c.namedBindings && ts.isNamespaceImport(c.namedBindings)) local.set(c.namedBindings.name.text, "imported-namespace");
    }
  }
  // A name can be declared twice — `export const X = z.object(…)` beside `export type X = …` — so a
  // later declaration must MERGE with the earlier one, never overwrite it (a value would read as a type).
  class MergeMap extends Map {
    set(name, kind) {
      const prev = super.get(name);
      if (prev === undefined || prev === kind) return super.set(name, kind);
      if (prev === "type") return super.set(name, `${kind}+type`);
      if (kind === "type") return super.set(name, prev.endsWith("+type") ? prev : `${prev}+type`);
      return super.set(name, `${prev}|${kind}`);
    }
  }
  const names = new MergeMap();
  const stars = [];
  for (const st of sf.statements) {
    const exported = hasMod(st, ts.SyntaxKind.ExportKeyword);
    const isDefault = hasMod(st, ts.SyntaxKind.DefaultKeyword);
    if (exported && (ts.isFunctionDeclaration(st) || ts.isClassDeclaration(st))) {
      const k = ts.isFunctionDeclaration(st) ? "function" : "class";
      names.set(isDefault ? "default" : st.name?.text ?? "default", k);
    } else if (exported && (ts.isInterfaceDeclaration(st) || ts.isTypeAliasDeclaration(st))) names.set(st.name.text, "type");
    else if (exported && ts.isEnumDeclaration(st)) names.set(st.name.text, "enum");
    else if (exported && ts.isVariableStatement(st)) {
      for (const d of st.declarationList.declarations) if (ts.isIdentifier(d.name)) names.set(d.name.text, initKind(d.initializer));
    } else if (ts.isExportAssignment(st)) {
      names.set("default", ts.isIdentifier(st.expression) ? local.get(st.expression.text) ?? "alias" : initKind(st.expression));
    } else if (ts.isExportDeclaration(st)) {
      if (st.moduleSpecifier !== undefined && ts.isStringLiteral(st.moduleSpecifier)) {
        const r = resolveSpec(rel, st.moduleSpecifier.text);
        if (st.exportClause === undefined) stars.push(r.rel ?? st.moduleSpecifier.text);
        else if (ts.isNamedExports(st.exportClause)) {
          for (const s of st.exportClause.elements) names.set(s.name.text, st.isTypeOnly || s.isTypeOnly ? "type" : `reexport(${r.rel ?? st.moduleSpecifier.text})`);
        } else names.set(st.exportClause.name.text, `namespace-reexport(${r.rel ?? "?"})`);
      } else if (st.exportClause !== undefined && ts.isNamedExports(st.exportClause)) {
        for (const s of st.exportClause.elements) {
          const localName = (s.propertyName ?? s.name).text;
          names.set(s.name.text, st.isTypeOnly || s.isTypeOnly ? "type" : local.get(localName) ?? "local-unknown");
        }
      }
    }
  }
  return { names, stars };
}
function kindOf(rel, name, depth = 0) {
  if (depth > 6) return "unresolved-depth";
  const { names, stars } = exportKinds(rel);
  const k = names.get(name);
  if (k !== undefined) {
    const m = /^reexport\((.+)\)$/.exec(k);
    if (m !== null && isFile(m[1])) return `${kindOf(m[1], name, depth + 1)} via re-export`;
    return k;
  }
  for (const s of stars) {
    if (!isFile(s)) continue;
    const kk = kindOf(s, name, depth + 1);
    if (kk !== "absent") return `${kk} via export *`;
  }
  return "absent";
}

  if (ts.isForOfStatement(p) && p.expression === n) return "iterate";
  if (ts.isSpreadElement(p) || ts.isSpreadAssignment(p)) return "spread";
  if (ts.isVariableDeclaration(p) && p.initializer === n) {

        const u = unwrap(x);
        const q = u.parent;
        if ((ts.isPropertyAccessExpression(q) || ts.isElementAccessExpression(q)) && q.expression === u) uses.add("var-deref");
        else if (ts.isCallExpression(q) && q.expression === u) uses.add("var-called");
        else if (ts.isForOfStatement(q) && q.expression === u) uses.add("var-iterate");
        else if (ts.isSpreadElement(q) || ts.isSpreadAssignment(q)) uses.add("var-spread");
        else uses.add("var-value");
      }
      ts.forEachChild(x, walk);
    };
    walk(sf);
    return uses.size === 0 ? "var-unused" : [...uses].sort().join("+");
  }
  if (ts.isCallExpression(p) && p.arguments.includes(n)) return "argument";
  return "other";
}
function usageOf(checker, sf, localNameNode) {
  const sym = checker.getSymbolAtLocation(localNameNode);
  const counts = {};
  const resultUses = {};
  const bump = (o, k) => {
    o[k] = (o[k] ?? 0) + 1;
  };
  if (sym === undefined) return { counts: { "no-symbol": 1 }, resultUses };
  const walk = (x) => {
    if (ts.isIdentifier(x) && x !== localNameNode && checker.getSymbolAtLocation(x) === sym) {
      const u = unwrap(x);
      const p = u.parent;
      if (ts.isTypeReferenceNode(p) || ts.isTypeQueryNode(p) || ts.isQualifiedName(p) || (ts.isExpressionWithTypeArguments(p) && ts.isHeritageClause(p.parent) && p.parent.token === ts.SyntaxKind.ImplementsKeyword)) bump(counts, "type-position");
      else if (ts.isExpressionWithTypeArguments(p) && ts.isHeritageClause(p.parent)) bump(counts, "extends");
      else if (ts.isCallExpression(p) && p.expression === u) {
        bump(counts, "call");
        bump(resultUses, `call→${resultUse(checker, p, sf)}`);
      } else if (ts.isNewExpression(p) && p.expression === u) {
        bump(counts, "new");
        bump(resultUses, `new→${resultUse(checker, p, sf)}`);
      } else if (ts.isTaggedTemplateExpression(p) && p.tag === u) bump(counts, "tagged-template");
      else if (ts.isPropertyAccessExpression(p) && p.expression === u) {
        const q = unwrap(p).parent;
        if (q && ts.isCallExpression(q) && unwrap(p) === q.expression) {
          bump(counts, "method-call");
          bump(resultUses, `method→${resultUse(checker, q, sf)}`);
        } else bump(counts, "member");
      } else if (ts.isElementAccessExpression(p) && p.expression === u) bump(counts, "member");
      else if ((ts.isJsxOpeningElement(p) || ts.isJsxSelfClosingElement(p)) && p.tagName === u) bump(counts, "jsx");

      } else if (ts.isTypeOfExpression(p)) bump(counts, "typeof");

      else if (ts.isShorthandPropertyAssignment(p)) bump(counts, "value");
      else bump(counts, "value");
    }
    ts.forEachChild(x, walk);
  };
  walk(sf);
  return { counts, resultUses };
}

/** node:test via the A.3 reporter module. Children arrive before their suite; rebuild paths from event order. */
export function fromNodeJsonl(text) {
  const pending = new Map();
  for (const line of text.split("\n")) {
    if (line.trim() === "") continue;
    const e = JSON.parse(line);
    if (e.type !== "test:pass" && e.type !== "test:fail") continue;
    const n = e.nesting ?? 0;
    const children = pending.get(n + 1) ?? [];
    for (const c of children) c.ancestors.unshift(e.name);
    pending.set(n + 1, []);
    const level = pending.get(n) ?? [];
    if (e.testType !== "suite") {
      const outcome = e.todo !== undefined ? "todo" : e.skip !== undefined ? "skip" : e.type === "test:pass" ? "pass" : "fail";
      level.push({
        ancestors: [],
        name: e.name,
        outcome,
        errorName: e.causeName,
        errorCode: e.causeCode,
        failureType: e.failureType,
        message: e.causeMessage ?? "",
      });
    }
    level.push(...children);
    pending.set(n, level);
  }
  return pending.get(0) ?? [];
}

function decode(s) {
  return s.replace(/&#10;/g, "\n").replace(/&apos;/g, "'").replace(/&quot;/g, '"').replace(/&lt;/g, "<").replace(/&gt;/g, ">").replace(/&amp;/g, "&");

  const m = new RegExp(`\\b${key}="([^"]*)"`).exec(attrs);

/** bun test --reporter=junit. suites[0] is bun's per-FILE wrapper; the describe path starts below it. */
export function fromBunJunit(text) {
  const rows = [];
  const suites = [];
  let current = null;
  const tag = /<(\/?)(testsuite|testcase|failure|skipped|error)\b([^>]*?)(\/?)>/g;
  for (let m = tag.exec(text); m !== null; m = tag.exec(text)) {
    const [, closing, name, attrs, selfClosing] = m;
    if (name === "testsuite") {
      if (closing === "/") suites.pop();
      else if (selfClosing !== "/") suites.push(attr(attrs, "name") ?? "");
    } else if (name === "testcase") {
      if (closing === "/") {
        current = null;
        continue;
      }
      current = { ancestors: suites.slice(1), name: attr(attrs, "name") ?? "", outcome: "pass", errorName: undefined, errorCode: undefined, failureType: undefined, message: "" };
      rows.push(current);
      if (selfClosing === "/") current = null;
    } else if ((name === "failure" || name === "error") && closing !== "/" && current !== null) {
      current.outcome = "fail";
      current.errorName = attr(attrs, "type");
      current.message = (attr(attrs, "message") ?? "").split("\n")[0];
    } else if (name === "skipped" && closing !== "/" && current !== null) {
      current.outcome = attr(attrs, "message") === "TODO" ? "todo" : "skip";
    }

export function redKind(row) {
  if (row.outcome !== "fail") return null;
  if (row.errorCode === "ERR_ASSERTION" || row.errorName === "AssertionError") return "assertion";
  if (row.failureType === "testTimeoutFailure" || /\btimed? ?out\b/i.test(row.message)) return "timeout";
  const code = row.errorCode === undefined ? "" : `[${row.errorCode}]`;
  return `${row.errorName ?? "unknown"}${code}`;
}

/** Value names a skeleton must export: every non-type binding the importer(s) name, deduplicated. */
export function exportNames(bindings) {
  return [...new Set(bindings.filter((b) => !b.typeOnly && b.imported !== "*").map((b) => b.imported))].sort();
}

/**
 * K1 — ADR-0573 D4's literal skeleton: every imported symbol exists and returns nothing. Each value
 * binding is a plain function returning undefined, so it is callable AND constructible (`new` yields an
 * empty instance) and carries no members of its own.
 */
export function skeletonK1(names) {
  const lines = ["// GENERATED (inc-05 measurement) — K1: every imported symbol exists and returns nothing."];
  names.forEach((n, i) => {
    lines.push(`function __stub${i}(..._args: any[]): any { return undefined; }`);
    lines.push(n === "default" ? `export default __stub${i};` : `export { __stub${i} as ${n} };`);
  });
  if (names.length === 0) lines.push("export {};");
  return `${lines.join("\n")}\n`;
}

/**
 * K2 — the absorbing variant, measured to price a rule of its own: every value binding is a proxy that is
 * callable and constructible, and every call, construction or member read returns another such proxy.
 * It is never a thenable (so `await` settles), converts to "" / NaN, iterates as empty, and leaves every
 * other well-known symbol at its default so `instanceof` and friends keep ordinary semantics.
 */
export function skeletonK2(names) {
  const lines = [
    "// GENERATED (inc-05 measurement) — K2: every imported symbol absorbs calls, construction and member reads.",
    "const __handler: ProxyHandler<any> = {",
    "  get(_target, key) {",
    '    if (key === "then" || key === "toJSON" || key === "$$typeof") return undefined;',
    '    if (key === Symbol.toPrimitive) return (hint: string) => (hint === "number" ? Number.NaN : "");',
    "    if (key === Symbol.iterator) return function* () {};",
    "    if (key === Symbol.asyncIterator) return async function* () {};",
    '    if (typeof key === "symbol") return undefined;',
    '    if (key === "toString" || key === "valueOf") return () => "";',
    "    return __make();",
    "  },",
    "  apply() {",
    "    return __make();",
    "  },",
    "  construct() {",
    "    return __make();",
    "  },",
    "};",
    "function __make(): any {",
    "  return new Proxy(function () {}, __handler);",
    "}",
  ];
  names.forEach((n, i) => {
    lines.push(`const __stub${i}: any = __make();`);
    lines.push(n === "default" ? `export default __stub${i};` : `export { __stub${i} as ${n} };`);
  });
  if (names.length === 0) lines.push("export {};");
  return `${lines.join("\n")}\n`;
}

  if (u.runner === "bun") return { pass: num(/^\s*(\d+) pass$/m), fail: num(/^\s*(\d+) fail$/m), skip: num(/^\s*(\d+) skip$/m) + num(/^\s*(\d+) todo$/m) };
  const line = /^\s*Tests\s+(.+)$/m.exec(out)?.[1] ?? "";
  const part = (w) => Number(new RegExp(`(\\d+) ${w}`).exec(line)?.[1] ?? 0);
  return { pass: part("passed"), fail: part("failed"), skip: part("skipped") + part("todo") };
}
function joinedCounts(r, variant) {
  const c = { pass: 0, fail: 0, skip: 0 };
  const count = (s) => {
    if (s === "pass") c.pass += 1;
    else if (s === "fail") c.fail += 1;
    else if (s === "skip" || s === "todo") c.skip += 1;
  };
  for (const t of r.tests) if (t[variant] !== undefined) count(t[variant].status);
  for (const x of r.undeclaredRows[variant] ?? []) count(x.outcome);
  return c;
}

const HOOKS = new Set(["beforeEach", "beforeAll", "afterEach", "afterAll", "before", "after"]);
const TEST_ROOTS = new Set(["describe", "test", "it"]);
function calleeParts(expr) {
  const members = [];
  let n = expr;
  for (;;) {
    if (ts.isPropertyAccessExpression(n)) {
      members.push(n.name.text);
      n = n.expression;
    } else if (ts.isCallExpression(n) || ts.isParenthesizedExpression(n) || ts.isNonNullExpression(n)) n = n.expression;
    else break;
  }
  return { root: ts.isIdentifier(n) ? n.text : undefined, members };
}
const inTypePosition = (x) => {
  for (let p = x.parent, i = 0; p !== undefined && i < 6; p = p.parent, i += 1) if (ts.isTypeNode(p)) return true;
  return false;
};
function staticTests(u) {
  const abs = `${WS}/${u.testFile}`;
  const program = ts.createProgram([abs], { noResolve: true, noLib: true, allowJs: true, jsx: ts.JsxEmit.Preserve, target: ts.ScriptTarget.ESNext, module: ts.ModuleKind.ESNext, types: [] });
  const sf = program.getSourceFile(abs);
  const checker = program.getTypeChecker();
  const locals = new Map();
  for (const i of u.imports) {
    if (!i.inScope) continue;
    for (const b of i.bindings ?? []) {
      if (b.typeOnly) continue;
      locals.set(b.local, { ...b, module: i.resolved, form: b.imported === "default" ? "default" : b.imported === "*" ? "namespace" : "named" });
    }
  }
  const bindingBySym = new Map();
  for (const st of sf.statements) {
    if (!ts.isImportDeclaration(st) || st.importClause === undefined) continue;
    const c = st.importClause;
    const nodes = [];
    if (c.name) nodes.push(c.name);
    if (c.namedBindings && ts.isNamespaceImport(c.namedBindings)) nodes.push(c.namedBindings.name);
    if (c.namedBindings && ts.isNamedImports(c.namedBindings)) for (const s of c.namedBindings.elements) nodes.push(s.name);
    for (const n of nodes) {
      const info = locals.get(n.text);
      const sym = checker.getSymbolAtLocation(n);
      if (info !== undefined && sym !== undefined) bindingBySym.set(sym, info);
    }
  }
  const contributors = new Map();
  const addContrib = (sym, node) => {
    if (sym === undefined || node === undefined) return;
    contributors.set(sym, [...(contributors.get(sym) ?? []), node]);
  };
  const hooksByContainer = new Map();
  const testCalls = [];
  const walkDecl = (x, ancestors) => {
    let childAncestors = ancestors;
    if (ts.isFunctionDeclaration(x) && x.name) addContrib(checker.getSymbolAtLocation(x.name), x);
    else if (ts.isClassDeclaration(x) && x.name) addContrib(checker.getSymbolAtLocation(x.name), x);
    else if (ts.isVariableDeclaration(x) && ts.isIdentifier(x.name)) addContrib(checker.getSymbolAtLocation(x.name), x.initializer);
    else if (ts.isVariableDeclaration(x) && x.initializer !== undefined) {
      const bind = (name) => {
        if (ts.isIdentifier(name)) addContrib(checker.getSymbolAtLocation(name), x.initializer);
        else for (const el of name.elements) if (!ts.isOmittedExpression(el)) bind(el.name);
      };
      bind(x.name);
    } else if (ts.isBinaryExpression(x) && x.operatorToken.kind === ts.SyntaxKind.EqualsToken && ts.isIdentifier(x.left)) addContrib(checker.getSymbolAtLocation(x.left), x.right);
    else if (ts.isCallExpression(x)) {
      const { root, members } = calleeParts(x.expression);
      if (root !== undefined && HOOKS.has(root)) {
        const container = ancestors.at(-1)?.node ?? sf;
        hooksByContainer.set(container, [...(hooksByContainer.get(container) ?? []), x]);
      } else if (root !== undefined && TEST_ROOTS.has(root) && !(members.includes("each") && !ts.isCallExpression(x.expression))) {
        const title = readTestCallTitle(x.arguments[0]);
        if (title !== null) {
          testCalls.push({ node: x, key: pathKey(ancestors.map((a) => a.title), title.text), ancestors });
          childAncestors = [...ancestors, { node: x, title: title.text }];
        }
      }
    }
    ts.forEachChild(x, (c) => walkDecl(c, childAncestors));
  };
  walkDecl(sf, []);
  const memo = new Map();
  const direct = (node) => {
    if (memo.has(node)) return memo.get(node);
    const b = new Set();
    const s = new Set();
    const w = (x) => {
      if (ts.isIdentifier(x) && !inTypePosition(x)) {
        const sym = checker.getSymbolAtLocation(x);
        if (sym !== undefined) {
          if (bindingBySym.has(sym)) b.add(sym);
          else if (contributors.has(sym)) s.add(sym);
        }
      }
      ts.forEachChild(x, w);
    };
    w(node);
    const r = { b, s };
    memo.set(node, r);
    return r;
  };
  const closure = (nodes) => {
    const bindings = new Set();
    const seen = new Set();
    const queue = [...nodes];
    while (queue.length > 0) {
      const { b, s } = direct(queue.shift());
      for (const x of b) bindings.add(x);
      for (const sym of s) {
        if (seen.has(sym)) continue;
        seen.add(sym);
        queue.push(...contributors.get(sym));
      }
    }
    return [...bindings].map((sym) => bindingBySym.get(sym));
  };
  const out = new Map();
  for (const t of testCalls) {
    const roots = t.node.arguments.slice(1);
    for (const a of [{ node: sf }, ...t.ancestors]) roots.push(...(hooksByContainer.get(a.node) ?? []));
    const bindings = closure(roots);
    const assertions = [];
    const w = (x) => {
      if (ts.isCallExpression(x)) {
        const { root, members } = calleeParts(x.expression);
        if (root === "assert" || root === "expect" || members.includes("assert")) assertions.push(x.getText(sf).replace(/\s+/g, " ").slice(0, 170));
      }
      ts.forEachChild(x, w);
    };
    for (const a of t.node.arguments.slice(1)) w(a);
    out.set(t.key, { bindings: bindings.map((b) => ({ local: b.local, imported: b.imported, form: b.form, kind: b.kindAtHead, module: b.module })), assertions: assertions.slice(0, 5) });
  }
  return out;
}

// ── 3. causes of a wrong-kind red ─────────────────────────────────────────────────────────────────
function cause(x) {
  const m = x.message ?? "";
  const k = x.kind ?? "";
  if (k === "timeout") return "the runner's per-test timeout";
  // vitest's json carries its timeout as a placeholder stack ("Error: STACK_TRACE_ERROR"); the default
  // reporter's console for the same run prints "Test timed out in <n>ms" (write-broker, verified).
  if (/^Error: STACK_TRACE_ERROR$|STACK_TRACE_ERROR/.test(m)) return "the runner's per-test timeout";
  if (/did not settle|timed out waiting|waitFor/i.test(m)) return "an awaited effect never happened (the test's own wait expired)";
  if (k.startsWith("TestingLibraryElementError")) return "a DOM query found nothing (the stub component rendered nothing)";
  if (/ENOENT/.test(m)) return "I/O on an effect the stub never produced (ENOENT)";
  if (k.startsWith("ZodError")) return "the test validated the stub's return against a schema";
  if (k.startsWith("SyntaxError") && /JSON|Unexpected (end|token)/i.test(m)) return "parsed a stub value as JSON";
  if (/ERR_INVALID_URL|Invalid URL|parse URL/i.test(`${k} ${m}`)) return "a stub value used as a URL";
  if (/ERR_INVALID_RETURN_VALUE|ERR_INVALID_ARG_TYPE/.test(k) || /must be (an instance of|of type)|Expected instance of Promise|is not a promise|must return a Promise/i.test(m)) return "an assert API refused a stub value (e.g. assert.rejects on undefined)";
  if (/Cannot destructure|destructur/i.test(m)) return "destructured the stub's return";
  if (/is not iterable|Spread syntax requires|Symbol\.iterator/.test(m)) return "iterated or spread a stub value";
  if (/is not a constructor/.test(m)) return "constructed a non-constructor";
  if (/is not a function/.test(m)) return "called a member the stub does not have";
  if (/Cannot read propert(y|ies) of (undefined|null)|(undefined|null) is not an object/.test(m)) return "read a property of the stub's return";
  return `other: ${k} — ${m.slice(0, 90)}`;
}

const SCR = process.env.SCR;
const TSX = process.env.TSX;
const { fromNodeJsonl, fromBunJunit, redKind, skeletonK1, skeletonK2 } = await import(`file:///${SCR}/lib.mjs`);

const show = (r) => (r === undefined ? "not reported" : r.outcome === "fail" ? `red — ${redKind(r)}` : r.outcome === "pass" ? "PASSED" : r.outcome);
for (const [label, gen] of [
  ["K1", skeletonK1],
  ["K2", skeletonK2],
]) {
  writeFileSync(`${DIR}/subject.ts`, gen(["add", "clamp", "parsePort"]));
  for (const file of ["cluster.test.ts", "guardrail.test.ts"]) {
    rmSync(`${DIR}/node.jsonl`, { force: true });
    rmSync(`${DIR}/bun.xml`, { force: true });
    spawnSync(process.execPath, ["--import", TSX, "--test", "--test-force-exit", `--test-reporter=file:///${SCR}/reporters/jsonl-reporter.mjs`, `--test-reporter-destination=${DIR}/node.jsonl`, file], { cwd: DIR, encoding: "utf8" });
    spawnSync("bun", ["test", "--reporter=junit", `--reporter-outfile=${DIR}/bun.xml`, `./${file}`], { cwd: DIR, encoding: "utf8" });
    const nodeRows = existsSync(`${DIR}/node.jsonl`) ? fromNodeJsonl(readFileSync(`${DIR}/node.jsonl`, "utf8")) : [];
    const bunRows = existsSync(`${DIR}/bun.xml`) ? fromBunJunit(readFileSync(`${DIR}/bun.xml`, "utf8")) : [];
    console.log(`\n## ${label} — ${file}`);
    for (const r of nodeRows) {
      const b = bunRows.find((x) => x.name === r.name);
      console.log(`  node: ${show(r).padEnd(28)} bun: ${show(b).padEnd(28)} ${r.name.slice(0, 70)}`);
    }
  }
}
rmSync(`${DIR}/subject.ts`, { force: true });
